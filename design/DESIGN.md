# Chill Design System

## Brand Feeling

Chill should feel:

- Calm
- Friendly
- Private
- Intelligent
- Simple
- Trustworthy

## Visual Style

- Clean layout
- Rounded cards
- Soft shadows
- Large tap targets
- Plenty of spacing
- Minimal clutter

## Typography

- Font: System default or Inter if supported.
- Title: 24px, semibold.
- Heading: 20px, semibold.
- Body: 16px, regular.
- Caption: 13px, regular.

## Spacing

Use a 4px scale:

```text
xs: 4
sm: 8
md: 16
lg: 24
xl: 32
```

## Components

### Buttons

- Rounded: 16px
- Padding vertical: 14px
- Padding horizontal: 20px
- Primary button: teal background, white text
- Secondary button: white background, border, dark text
- Danger button: red background, white text

### Cards

- Background: white
- Border radius: 20px
- Padding: 20px
- Border: 1px solid #E2E8F0
- Soft shadow

### Input Fields

- Rounded: 14px
- Border: 1px solid #E2E8F0
- Padding: 14px
- Focus border: primary color

### Voice Recording Card

- Large circular mic button
- Animated recording indicator
- Phrase text
- Progress indicator
- Retry button
